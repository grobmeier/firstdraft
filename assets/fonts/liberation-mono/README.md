# Liberation Mono 2.1.5

Unmodified regular and bold TTFs from the official Liberation Fonts release:

https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5

Archive: https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz

Archive SHA-256:
`7191c669bf38899f73a2094ed00f7b800553364f90e2637010a69c0e268f25d0`

The upstream copyright and SIL Open Font License 1.1 are reproduced in
`LICENSE`. The plugin build embeds the font bytes and full licence in `main.js`;
exports subset the glyphs used. No font download is performed at runtime.

Representative extended Latin, Greek and Cyrillic text is tested. This font
does not supply general CJK or emoji coverage. PDF export validates each
character against the actual font character set and stops on missing glyphs.
