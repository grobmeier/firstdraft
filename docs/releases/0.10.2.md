# First Draft 0.10.2

This maintenance release keeps the writing experience unchanged while making
the contextual First Draft Palette easier to maintain and extend safely.

## Improvements

- The palette now separates character dossiers, screenplay projects, writing
  actions, and recent items into focused internal modules.
- Asynchronous palette updates still discard stale results when the active note
  changes.
- GitHub Actions and compatible development dependencies are updated.
- The project now builds with TypeScript 6 and its current compiler guidance.

## Compatibility

- Requires Obsidian 1.13.7 or later.
- Desktop and mobile remain supported.
- The release contains only `main.js`, `manifest.json`, and `styles.css`, with
  GitHub build-provenance attestations for all three.
