# First Draft 0.10.1

This scanner-compliance release keeps the first public feature set intact while
aligning the plugin and its release assets with current Obsidian guidance.

## Improvements

- First Draft no longer detaches its sidebar palette during unload, preserving
  the location chosen by the user.
- Timers work correctly in Obsidian popout windows.
- Command names no longer repeat the plugin name.
- Settings use Obsidian's searchable declarative settings API.
- Deprecated slider tooltip calls and unnecessary type assertions are removed.
- Export collision checks inspect only candidate paths instead of enumerating
  all vault files.
- The release contains only `main.js`, `manifest.json`, and `styles.css`, and
  GitHub publishes build-provenance attestations for all three.

## Privacy notes

Project and character discovery examines Markdown paths and cached frontmatter
across the vault. Screenplay contents are read only for the active screenplay
and its explicitly linked project parts. The cheat sheet writes to the clipboard
only when **Copy** is pressed and never reads clipboard contents.

## Compatibility

- Requires Obsidian 1.13.7 or later.
- Desktop and mobile remain supported.
