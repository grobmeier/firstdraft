# First Draft 0.13.1 beta 2 — iPad palette test

This is an opt-in prerelease for testing, not a replacement for stable 0.13.0.
In BRAT, use repository `grobmeier/firstdraft` and explicitly select tag
`0.13.1-beta.2`. The release tag and manifest version match exactly.
Restart Obsidian or disable/re-enable First Draft after installing the update.
Keep this version frozen in BRAT. Use BRAT to switch back to a stable release
after testing; Obsidian may not automatically replace a beta with the same
numeric patch version. Beta 1 was cancelled before publication.

## Fixes

- Retain the open note context when the palette takes focus, but reject stale
  editors when navigating to another note or closing a view.
- Prefer current editor properties over stale cached properties. Unknown or
  malformed properties show a waiting message rather than an activation prompt.
- Refresh controls after activation and provide feedback for already-active notes.
- Character controls also use the current note properties.

## Please test on iPad

Use a disposable test vault. Open a Markdown note with boolean `screenplay: true`.
Open/close and focus the palette repeatedly, switch between reading and editing,
create a project, navigate its parts, and return to the original screenplay.
Writing controls should remain available without asking for activation again.
Then switch to ordinary notes, empty tabs, projects and character pages: controls
must follow the current note, and actions must never edit a previous note.

See [the focused mobile checklist](../MOBILE_TESTING.md) for property changes,
restart/resume checks and the details to include with a failure report.

## Validation and limitations

218 automated tests pass, including 24 new regressions. Build, lint, formatting
and Apache header checks pass. The isolated desktop test vault has the test
build installed; these checks do not reproduce or verify the physical iPad bug.
The exact device trigger and physical mobile acceptance remain unverified.

All processing stays local; no network requests, clipboard access or whole-vault
enumeration are added. Requires Obsidian 1.13.7 or later. The existing offline
font bundle remains approximately 33 MB; device memory/performance still needs
testing. Only `main.js`, `manifest.json` and `styles.css` are released, with
GitHub build-provenance attestations.
