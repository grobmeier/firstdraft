# First Draft 0.13.0

## Scenes and source-linked continuity

- Open **Scenes** in the palette or **Open scene workspace** with Cmd/Ctrl+P.
  Navigate ordered project parts, search headings/synopses and filter by part,
  character, location or time. Cards show approximate page positions.
- Create scenes, edit portable Fountain `= Synopsis` lines and rearrange complete
  scene blocks. Single-file changes use editor transactions and normal Undo.
- Confirmed cross-part moves save a local recovery copy before writing.
  **Restore last move** refuses to overwrite later writing. Save both notes first;
  cross-file writes are not atomic and are not a single editor-undo action.
- **Inspect continuity** offers read-only character identity/link checks and
  optional dossier, empty-scene and missing-time advice. Evidence opens original
  sources; stale evidence requires Refresh. Incomplete coverage is explicit.
- Patched the development-only Moment dependency to 2.31.0.
- Updated the feature tour with desktop scene and inspector screenshots.

All processing stays local. No network requests, clipboard access or whole-vault
enumeration are introduced. Requires Obsidian 1.13.7 or later.

## Boundaries and validation

The inspector does not assess story logic, chronology, props or inferred character
presence. Scripts with sections, dual dialogue, boneyards, multiline notes or
fenced code remain navigable, but scene mutations are disabled to protect source
boundaries. Cross-part recovery requires ordinary non-hidden note paths.

Validation includes 194 automated tests, build/lint/format/licence checks and
isolated Obsidian desktop tests of native Edit → Undo, cross-part move/restore,
later-edit conflict refusal and stale-dialog rejection. Automated checks are not
physical-device proof. Narrow-sidebar acceptance and physical iPhone layout,
undo, memory/performance and PDF sharing remain unverified. The offline font
bundle is approximately 33 MB. Mobile compatibility is retained, not certified.

The dependency audit reports zero vulnerabilities. GitHub confirms Dependabot
alert #1 as fixed on 2026-10-04; the development dependency override remains
until upstream tooling resolves a patched copy.

Only `main.js`, `manifest.json` and `styles.css` are published as release assets,
with GitHub build-provenance attestations.
