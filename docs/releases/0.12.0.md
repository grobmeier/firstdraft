# First Draft 0.12.0

## More faithful, multilingual screenplay PDFs

- Optional title pages: use a leading Fountain title block, or `title`, `credit`,
  `author`, `source`, `draft-date` and `contact` properties on a screenplay or
  project note. No explicit title means no added cover. The cover is unnumbered;
  screenplay page numbering starts at 1.
- Continued dialogue: page breaks generate `(MORE)` and repeat the speaker with
  `(CONT'D)`, preserving extensions. Short speeches move together where possible.
  Parentheticals stay with dialogue. Generated markers never change your source.
- Offline Chinese (Simplified/Traditional), Japanese and Korean PDF support.
  Choose **Settings → First Draft → PDF language** for regional Han forms.
  English-only scripts are unaffected by this choice.
- Broader Latin, Greek and Cyrillic font coverage. Unsupported characters stop
  export with a clear diagnostic rather than silently becoming question marks.
- Easier screenplay activation from the palette and command menu.

All PDF generation stays local. Existing files are never overwritten. Requires
Obsidian 1.13.7 or later and retains mobile compatibility.

## Boundaries and validation

The plugin bundle is about 33 MB because fonts are included offline; exported
PDFs embed only used glyphs. Physical iPhone memory/performance validation is
still outstanding. CJK preview line breaks/page counts are approximate—review
the exported PDF. Emoji, universal Unicode, vertical text, ruby, dual dialogue,
locked production pages and exact Final Draft pagination are not promised.
Oversized title metadata or parentheticals fail safely instead of clipping.

Validation includes automated metadata/pagination/export tests, rendered
Letter/A4 Latin/CJK samples and isolated desktop Obsidian preview/export checks.
Earlier offline mobile-WebKit tests cover CJK export, not physical-phone proof.

Only `main.js`, `manifest.json` and `styles.css` are published as release assets,
with GitHub build-provenance attestations.
