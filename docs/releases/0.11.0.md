# First Draft 0.11.0

First Draft 0.11 adds the first end-to-end reading workflow: preview a
standalone or multi-file screenplay as pages, then export the same layout to a
local PDF without leaving Obsidian.

## Highlights

- Preview six core screenplay elements with Courier typography, screenplay
  margins, deterministic wrapping, page breaks, and page numbers.
- Export non-destructive PDFs in the configured US Letter or A4 size. Existing
  files are never overwritten.
- Combine explicitly ordered project parts into one preview and PDF.
- Remove broad vault enumeration from project and character discovery.
- Remove plugin clipboard access; cheat-sheet examples remain selectable for
  the normal copy shortcut.
- Add a visual feature tour, desktop screenshots, and a short demo.

The source Fountain or Markdown remains authoritative. Preview and PDF export
run locally without accounts, telemetry, or network requests.

PDF output is intended for reading and review, not locked studio production
pagination. See the repository's PDF and FDX compatibility documents for the
exact supported boundaries.

Requires Obsidian 1.13.7 or later. Desktop verification is complete; the
documented physical-device mobile checklist remains the final mobile acceptance
step.
