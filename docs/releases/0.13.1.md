# First Draft 0.13.1 — Sync-safe bundle and palette fixes

Requires Obsidian 1.13.7 or later. This stable patch includes the fixes tested
in beta 3 plus build-time Latin font embedding and a dependency security update.

## Upgrade notes

- Update through Obsidian's Community plugins settings, then restart Obsidian
  or disable/re-enable First Draft. Existing notes and settings are preserved.
- **CJK PDF export now requires a one-time offline font installation on each
  device.** Run **Install offline CJK PDF fonts**, select both official WOFF
  files, and install. See [downloads and instructions](https://github.com/grobmeier/firstdraft/blob/main/docs/CJK_FONT_PACK.md).
  Keep original downloads outside a Sync Standard vault; the installed fonts
  use six chunks of at most 4 MB. Do not assume auxiliary plugin files sync.
- Latin, Greek and Cyrillic PDF fonts remain built in. CJK writing, preview,
  scene planning and Fountain/FDX export need no font pack. Missing or corrupt
  CJK fonts stop PDF export with instructions, without saving a partial PDF.
- BRAT beta testers: select stable `0.13.1` explicitly in BRAT. Obsidian may not
  automatically replace `0.13.1-beta.3` with the corresponding stable version.

## Fixes and security

- Reduce `main.js` from 33.5 MB to approximately **3.34 MB**. Builds reject any
  standard release asset at or above 5,000,000 bytes.
- Retain the current note when the palette takes focus, reject stale views
  during navigation and use current editor properties rather than stale cache.
  Unknown/malformed metadata waits instead of incorrectly offering activation.
- Embed Latin PDF fonts as byte arrays at build time, removing native `atob()`
  and `btoa()` calls. Builds reject their reintroduction. PDF dependencies still
  contain legitimate data-encoding utilities; a broader scanner may flag those.
- Update development-only `source-map-js` to patched 1.2.2. Dependency audit
  reports zero known vulnerabilities at release preparation.
- Standard assets remain only `main.js`, `manifest.json` and `styles.css`, built
  and attested by GitHub Actions. No automatic downloads, telemetry, clipboard
  access or whole-vault enumeration are introduced.

Unavailable malware/obfuscation scans are external scanner results, not checks
we can enable in the plugin. They do not establish either a clean or malicious
release. See [scanner notes](https://github.com/grobmeier/firstdraft/blob/main/docs/SECURITY_SCAN_NOTES.md).

## Validation and known limitations

246 automated tests pass, including byte-for-byte font checks, PDF coverage,
palette regressions and bundle guards. Build, lint, formatting, licence checks
and audit pass. Twelve Latin/CJK PDF fixtures were generated; representative
Latin, Japanese and Korean output was rendered and visually checked.

Physical iPad palette behaviour, file-picker installation, exported-PDF viewing
and memory/performance **remain unverified**. The full CJK inventory is still
approximately 23.4 MB before decoding; the smaller bundle does not eliminate
export memory requirements. Narrow desktop-sidebar acceptance also remains
open. These are disclosed limitations, not completed device tests. Follow the
[mobile checklist](https://github.com/grobmeier/firstdraft/blob/main/docs/MOBILE_TESTING.md).
