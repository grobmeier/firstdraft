# First Draft 0.10.0

First Draft's first public release makes Obsidian a focused screenplay-writing
environment while keeping the screenplay itself as portable Fountain text.

## Highlights

- Write in `.fountain` files or opt Markdown notes into screenplay mode.
- Use screenplay-aware completion and keyboard-first commands for scenes,
  characters, extensions, parentheticals, and transitions.
- Keep a screenplay in one file or organise ordered parts across vault folders.
- See project-wide statistics, character checks, recent elements, and exports.
- Maintain portable Markdown character dossiers with relationships and derived
  screenplay appearances.
- Export non-destructively to Fountain or the supported Final Draft FDX subset.
- Reach common and recent actions from the dockable First Draft Palette.
- Create a safe example project from one command and consult an offline,
  copy-friendly screenplay and Fountain cheat sheet.
- Read ordered project parts one per line in both project properties and the
  First Draft Palette.

First Draft is local-only: it has no telemetry, accounts, cloud dependency, or
network access during ordinary use.

## Compatibility

- Obsidian 1.13.7 or later.
- Desktop and mobile are declared as supported.
- FDX export covers scene headings, action, characters, parentheticals,
  dialogue, and transitions. See `docs/FDX_COMPATIBILITY.md` for details.

## Installation

The release provides the three files required by Obsidian: `main.js`,
`manifest.json`, and `styles.css`. A convenience ZIP and SHA-256 checksums are
also attached.
