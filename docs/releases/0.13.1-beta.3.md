# First Draft 0.13.1 beta 3 — Sync-safe core and iPad palette fixes

This is an opt-in prerelease, not a replacement for stable 0.13.0. In BRAT,
use repository `grobmeier/firstdraft` and explicitly select `0.13.1-beta.3`.
The tag and manifest version match. Restart Obsidian or disable/re-enable First
Draft after installation. Keep the version frozen in BRAT; use BRAT to return
to a stable release after testing. Betas 1 and 2 were cancelled before publication.

## Smaller core, optional offline fonts

- The core JavaScript is approximately **2.35 MB**, down from 33.5 MB. All three
  standard assets are below Sync Standard's 5 MB per-file limit. Production
  builds and release CI reject assets at or above that limit.
- Latin PDFs work immediately. Chinese, Japanese and Korean PDF export now
  requires the optional offline font pack; other writing features and
  Fountain/FDX export do not need it.
- Run **Install offline CJK PDF fonts** and select both official WOFF files.
  [Font files, licence and instructions](https://github.com/grobmeier/firstdraft/blob/main/docs/CJK_FONT_PACK.md)
  are available separately. Both files are hash-verified before installation and
  stored as six chunks of at most 4 MB. They are verified again on export.
- Missing, incomplete or corrupt font packs stop export with actionable feedback
  instead of producing a partial PDF. Install the pack separately on each device;
  auxiliary plugin-file sync is not guaranteed. Keep the original downloads
  outside a Sync Standard vault because each WOFF exceeds 5 MB.

## Palette fixes

- Retain the current Markdown note when the palette takes focus; reject stale
  editors during navigation and when views close.
- Prefer current editor properties over stale cache entries. Unknown or malformed
  properties show waiting feedback instead of asking to activate the note.
- Refresh after activation and report an already-active note explicitly.

## Validation and remaining acceptance

240 automated tests pass, including 46 regressions added since 0.13.0. Build,
lint, formatting, licence-header and release-size checks pass. Latin and all four
regional CJK PDF fixtures were generated and visually reviewed. The isolated
test vault has the small core installed; its font pack is not preinstalled.

Physical iPad file-picker installation, palette behaviour, exported PDF viewing
and memory/performance remain unverified. Please follow the
[focused mobile checklist](https://github.com/grobmeier/firstdraft/blob/main/docs/MOBILE_TESTING.md).
The exact physical-device trigger of the palette report has not been reproduced.
The optional full font inventory remains approximately 23.4 MB before decoding;
shrinking the core does not eliminate CJK export memory requirements.

No automatic network requests, telemetry, clipboard access or whole-vault
enumeration are introduced. Requires Obsidian 1.13.7 or later. Only `main.js`,
`manifest.json` and `styles.css` are release assets, with GitHub build-provenance
attestations. The optional fonts retain their SIL Open Font License 1.1.
